# Sidekick v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu bar Mac app, Sidekick, with tools that can each be switched on or off. v1 ships two tools: Keep on Top (a live floating copy of any window) and Dictation (Parrot, moved in).

**Architecture:** A new XcodeGen project seeded from Parrot (`~/Documents/Parrot`). Every tool implements one `Tool` protocol. A `ToolRegistry` remembers which tools are on and starts or stops them. The window's sidebar, the first-run setup, and the menu bar menu are all built from the registry. Keep on Top mirrors a window through ScreenCaptureKit into a floating `NSPanel`. Dictation is Parrot's engine with its app-wide setup moved into a `DictationEnvironment` that only exists while the tool is on.

**Tech Stack:** Swift 6, SwiftUI + AppKit, macOS 26, arm64, XcodeGen, Sparkle 2.10.1, WhisperKit 1.1.1, KeyboardShortcuts (sindresorhus, 2.x), ScreenCaptureKit, SwiftData, swift-testing.

**Spec:** `docs/superpowers/specs/2026-11-20-sidekick-design.md`

## Global Constraints
- Deployment target macOS 26.0, `ARCHS: arm64`, `SWIFT_VERSION: "6.0"`, no sandbox, no hardened runtime. Same signing setup as Parrot, with identity `"Sidekick Self-Signed"`.
- Bundle ID `com.sidekick.app`; tests target `com.sidekick.app.tests`. Display name `Sidekick`. `LSUIElement = true`.
- Colors come only from `Theme.fg(_:)` and `Theme.bg(_:)`. Motion uses only `Motion.snappy`, `Motion.fluid`, and `Motion.gentle`. No linear or ease curves, no materials or blur.
- A tool that is off runs no code, registers no shortcut, and has no setup steps shown for it.
- Keep on Top is on by default on first run; Dictation is off.
- Keep on Top's default shortcut is ⌃⌥T. It can be changed with a KeyboardShortcuts recorder.
- The settings window is 800×560 and not resizable, with `host.sizingOptions = []`. Parrot's `MainWindowTests` must keep passing.
- Tests use swift-testing (`import Testing`, `@Test`, `#expect`) and run through `scripts/test.sh [Suite]`.
- Anything outward-facing (creating the GitHub repo, pushing, `gh release`, editing the Parrot repo) needs the user's confirmation at the time.

## Review Focus
1. **Screen Recording granted but not active until relaunch.** Pressing ⌃⌥T must open Keep on Top's setup mini-flow, not fail silently. Covered by test `shortcutWithoutPermissionRequestsSetup` (Task 6).
2. **No window to pin.** When the frontmost app has no normal window (the desktop/Finder, a menu bar-only app, or Sidekick itself), nothing gets pinned and the Mac beeps. Covered by `WindowFinderTests` cases for own-PID, layer≠0, and tiny windows (Task 5).
3. **Turning a tool off while it's in use.** Mirrors close and the dictation key tap stops. Covered by `ToolRegistryTests.disablingStopsTool` (Task 2), `PinControllerTests.unpinAllDismissesEveryMirror` (Task 5), and `DictationToolTests.stopTearsDown` (Task 7).
4. **A pinned copy's display goes away, or it's dragged partly off screen.** The copy is clamped back onto a visible screen. Covered by `PiPLayoutTests.clampsIntoScreen` (Task 5).
5. **Importer run twice, no Parrot data, or Sidekick already has history.** Nothing is overwritten or duplicated. Covered by the `ParrotImporterTests` cases (Task 8).

  speechModel, appleIntelligence, globeKey, practice, tryIt, finish }

  var title: String; var isGranted: Bool }            // isGranted reads Permissions.*
struct ToolPage: Identifiable { let id: String; let title: String; let content: @MainActor () -> AnyView }
struct ToolMenuItem: Identifiable { let id: String; let title: String; let shortcut: KeyboardShortcuts.Name?; let action: @MainActor () -> Void }
@MainActor protocol Tool: AnyObject {

  func isEnabled(_ id: String) -> Bool

enum Relauncher { static func relaunch() }    // Process `/bin/sh -c "sleep 0.5; open <bundlePath>"`, then NSApp.terminate

struct WindowInfo: Equatable, Sendable { let id: CGWindowID; let pid: pid_t; let frame: CGRect; let title: String; let appName: String }
enum WindowFinder {
  static func pick(from list: [[String: Any]], frontmostPID: pid_t, ownPID: pid_t, primaryScreenHeight: CGFloat) -> WindowInfo?
     // first entry (z-order) with kCGWindowLayer == 0, owner PID == frontmostPID != ownPID, width & height ≥ 100;
     // frame converted from CG (top-left origin) to AppKit (bottom-left): y = primaryScreenHeight - cgY - height
  static func frontmost() -> WindowInfo?          // live: CGWindowListCopyWindowInfo([.optionOnScreenOnly,.excludeDesktopElements], kCGNullWindowID)
  static func exists(_ id: CGWindowID) -> Bool    // in the full list (not on-screen-only)
  static func isOnScreen(_ id: CGWindowID) -> Bool
}
enum PiPLayout {
  static func pipFrame(source: CGRect, screen: CGRect, scale: CGFloat = 0.35, minWidth: CGFloat = 240, margin: CGFloat = 16) -> CGRect
     // aspect-preserving; placed in the screen corner nearest the source's center
  static func snapped(_ frame: CGRect, screen: CGRect, margin: CGFloat = 16) -> CGRect   // nearest corner, same size
  static func clamped(_ frame: CGRect, into screen: CGRect) -> CGRect                    // shrink to fit (keep aspect), then move inside
}
@MainActor protocol MirrorPresenting: AnyObject { func present(); func dismiss() }
@MainActor @Observable final class PinController {
  init(makeMirror: @escaping (WindowInfo) -> MirrorPresenting)
  private(set) var pins: [WindowInfo]
  func toggle(_ w: WindowInfo)        // pinned (same id) ⇒ unpin, else pin + present
  func unpin(_ id: CGWindowID)        // dismiss + remove; unknown id is a no-op
  func unpinAll()
}
